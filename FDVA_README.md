## 🚀 Mini Project — English Premier League Match Analytics

The mini-project applies the concepts learned throughout the FDVA experiments to an **English Premier League (EPL) match dataset**.

**Dataset:** `epl_final.csv`

### Dataset Features

The dataset contains match information such as:

- Home and Away Teams
- Home and Away Goals
- Match Results
- Shots
- Corners
- Yellow Cards
- Red Cards
- Match Date
- Season

### Tools Used

- Python
- Power BI
- Tableau

### Analysis Performed

The project focuses on:

- Season-wise goal trends
- Match result distribution
- Home vs Away performance
- Team performance
- Shots and goals relationship
- Highest-scoring matches
- Match statistics across seasons

The EPL dataset is cleaned and analyzed using Python, followed by the creation of interactive dashboards using **Power BI** and **Tableau**.
